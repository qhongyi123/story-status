# 版本（自留备忘 · 2026-10-06）

一个世界观可以有几套「版本」，玩家在前端点开世界观卡牌后、名字下面点按钮切换。

## 怎么放

```
世界观\{世界观名}\
    简介.txt               ← 整套世界观共用
    变量规则\自由.txt       ← 整套世界观共用
    开局\                  ← 整套世界观共用
    附录\                  ← 整套世界观共用
    版本\                  ← 有这个文件夹，界面才会出现版本按钮
        什么都没写\        ← 基础版（现在故意是空的；界面上排第一个）
            时代锚点\什么都没写.txt
            世界风格\什么都没写.txt
            社会与法治\什么都没写.txt
            民俗风情\什么都没写.txt
            背景设定\什么都没写.txt
            社会生态\什么都没写.txt
        版本二\
        版本三\
```

## 三条规矩

1. **文件名＝版本名**（跟它所在那一层文件夹同名）。例如 `版本\版本二\社会与法治\版本二.txt`。
   某个段落**不写就不显示**（连它的「＋ 添加」按钮都不显示）——和正文一个规矩。
2. **版本只管这六段**：时代锚点／世界风格／社会与法治／民俗风情／背景设定／社会生态。
   简介、变量规则、开局、附录**仍然是整套世界观共用**，不分版本。
3. 一个字都不写的版本＝**空世界观**（界面只显示什么都没写的样子）。

## 想加/改版本

- **加一个版本**：在 `版本\` 下复制一个文件夹改名（文件夹名＝按钮文字），把里面的 `{版本名}.txt` 一并改名。
- **改顺序**：按钮顺序＝`什么都没写` 排第一，其余**按名字排**。想固定顺序就在名字前加数字（如 `1-什么都没写`）。
- **改完必须重跑** `工具\生成世界观预置.ps1`，预置里才会带上新版本；前端也要重传 `worldviews.json`。

> 备注：从「伊菈优待」时期留下的根目录那几个段落文件夹（`时代锚点\`／`社会与法治\`／`民俗风情\`／`背景设定\`）还在原地，但**有了 `版本\` 之后它们不再参与显示**。要留就把内容搬进某个版本，要丢就删 —— 备份在 `待处理\世界观备份\`。
