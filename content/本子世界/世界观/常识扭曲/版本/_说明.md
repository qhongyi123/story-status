# 版本（自留备忘 · 2026-10-06，最后更新：同日晚）

一个世界观可以有几套「版本」，玩家在前端点开世界观卡牌后、名字下面点按钮切换。

## 怎么放

```
世界观\{世界观名}\
    简介.txt               ← 整套世界观共用
    开局\                  ← 整套世界观共用
    附录\                  ← 整套世界观共用（世界观级的附录池）
    变量规则\自由.txt       ← 兜底用：某一版没写自己的规则时，用这一份
    版本\                  ← 有这个文件夹，界面才会出现版本按钮
        什么都没写\        ← 基础版（故意留空；**界面上不出按钮**，只当兜底）
            时代锚点\什么都没写.txt
            世界风格\什么都没写.txt
            社会与法治\什么都没写.txt
            民俗风情\什么都没写.txt
            背景设定\什么都没写.txt
            社会生态\什么都没写.txt
        精液当货币的世界\
            时代锚点\精液当货币的世界.txt
            …（其余五段同理）
            变量规则\自由.txt          ← 这一版自己的变量规则（写进 uid 28）
            附录\{段落}\精液当货币的世界.txt   ← 这一版自己的附录池（可选）
        性开放的世界\
        伊菈随意性爱的世界\

另外，**变量信息展示**（uid 11 的 EJS）放在世界观外面：
状态栏\content\本子世界\变量信息展示\{世界观名}\{版本名}.txt
（世界观级那份仍是 变量信息展示\{世界观名}.txt；版本没写就沿用世界观级）
```

## 四条规矩

1. **文件名＝版本名**（跟它所在那一层文件夹同名）。例如 `版本\性开放的世界\社会与法治\性开放的世界.txt`。
   某个段落**不写就不显示**（连它的「＋ 添加」按钮都不显示）——和正文一个规矩。
2. **版本管这些**：时代锚点／世界风格／社会与法治／民俗风情／背景设定／社会生态 ＋ **各自的变量规则** ＋ **各自的变量信息展示** ＋ **各自的附录池**。
   只有 **简介、开局、世界观级附录** 是整套共用的。
3. 一个字都不写的版本＝**空版本**：界面上**不出按钮**（点了也是空的），也不会被当成默认版本 —— 默认落在**第一个有内容的版本**上。
4. **名字只给我们自己看**：世界观名／版本名**不会写进正文、变量规则、变量信息展示**（那些是要发给 AI 的）。界面按钮、文件夹名、预置的键名照用不误。

## 想加/改版本

- **加一个版本**：在 `版本\` 下复制一个文件夹改名（文件夹名＝按钮文字），把里面的 `{版本名}.txt` 一并改名；
  想给它单独的变量规则就加 `变量规则\自由.txt`，想给它单独的展示就加 `变量信息展示\{世界观名}\{版本名}.txt`。
- **改顺序**：按钮顺序＝按文件夹名排（`什么都没写` 永远第一个）。想固定顺序就在名字前加数字（如 `1-精液当货币的世界`）。
- **改完必须重跑** `工具\生成世界观预置.ps1`，预置里才会带上新版本；前端也要重传 `worldviews.json`。

> 备注 1：从「伊菈优待」时期留下的根目录那几个段落文件夹（`时代锚点\`／`社会与法治\`／`民俗风情\`／`背景设定\`）还在原地，但**有了 `版本\` 之后它们不再参与显示**。要留就把内容搬进某个版本，要丢就删 —— 备份在 `待处理\世界观备份\`。
> 备注 2：`生成世界观预置.ps1` 只把有内容的版本当作候选；状态栏则是拿 uid 54 的正文跟预置**逐条比对**来认"这是哪一套／哪一版"（因为正文里不写名字）。
