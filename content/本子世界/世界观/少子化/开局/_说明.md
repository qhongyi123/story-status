# 少子化的开局卡（自留备忘 · 2026-10-04）

- **一个 `.txt` ＝ 界面上的一张卡**，**文件名就是卡标题**（改名＝改标题）。
- 卡片上那句话简介 ＝「正文：」之后的**第一行**（超 46 字截断加 `…`）—— 由生成器自动取，**不要手写**。
- **同名 `.变量.json`（可选）＝ 这张卡开局时自带的初始变量**：前端点「开始剧情」时并进 payload（和 `setting`、`rules` 一起走）。
  - 只放 `world` / `user` / `characters` 三组；**不要放 `setting`、`rules`**（那是前端管的，会被前端覆盖）。
  - 字段名与取值必须符合 `..\变量规则\自由.txt`；跑 `node 工具\测试开局变量.js` 会逐条核对（含受孕状态能不能被选择器认出来）。
  - 改完这两类文件，要重跑 `工具\生成世界观预置.ps1`，预置里的 `openings[].vars` 才会更新；前端也要重传 `data/fh1-presets/worldviews.json`。
- **正文原样发送**：包含开头的 `<qy>` 外壳与 `地点／时间／天气` 三行（和以前那张开局一致），没有被剥掉。
- 现有五张卡：

| 卡（＝文件名） | 自带变量 |
|---|---|
| `作为外派授精师出差，享受美妙假期.txt` | 世界时间地点 + 玩家（外派授精师）＋ 林语（接待科） |
| `安平县四年来的第一位新授精师.txt` | 世界时间地点 + 玩家（安平县常备授精师）＋ 苏婉、苗苗 |
| `邻居的受孕请求.txt` | 世界时间地点 + 玩家（常备授精师，**故意不写性别**）＋ 沈婉、沈音 |
| `新学期的巡回授精.txt` | 世界时间地点 + 玩家（第三中学学生／外派授精师，**同样不写性别**）＋ 苏影、楚校长 |
| `挑瓷砖挑到老板娘身上.txt` | 世界时间地点 + 玩家（授精师／顾客）＋ 曹丽（瓷砖店老板娘） |

- **卡片顺序＝文件名排序**（生成器按名字排）。想调整顺序就改文件名。
- **「待更新」是不允许的**：变量规则「角色变量规则·注 1」写明——除 `gender` 外，其它字段没定就必须填充。所以 `沈婉.ring` 写「待更新」是不合规的，需要进行补充。
- **玩家性别一律留空（用户定的规矩，2026-10-05）**：
  - **四张卡的 `user` 里都没有 `gender` 键**；正文里凡是写玩家身体／性别的地方也清过了（"男式拖鞋""他""裆部隆起""鸡巴""肉棒""柱身""前列腺液"那些）。
  - **自测会盯住这一条**：`node 工具\测试开局变量.js` 里有一条「user 里没有 gender」，谁再写进去就会报红。
  - ⚠️ 但**前端变量模板**（`前端文件\js\core.js` 的 `emptyTemplateInfo`）本身就带 `user.gender: ""`，所以发出去的 payload 里这个键**存在、值为空串**。要彻底没有这个键，得改模板（会影响所有世界观），属于另一件事。
  - **保留没动的**：世界设定的性别体系（`男性 | 伊芙 | 伊菈`）、别人身上的描写（伊菈的阴茎／肉棒、学校里的"男娃娃"）、以及"授精师／受孕指标／精液"这类**职务机能**——那些不是玩家的性别。

> `_说明.md` 这种 `.md` 不会被当成卡（生成器只扫 `*.txt`），可以放心写备注。

# 开局大纲的格式（写新卡的统一规范 · 2026-10-05 定）【已作废，见文末新版】

做新开局分两步：**先出大纲（给 AI 落正文用）→ 再按大纲写卡**。大纲一律照下面的写法。

## 一、通用提醒（每份大纲末尾都带，内容固定不变）

1. 只能用「{{user}}」作为用户名称。其余人名一律中式，姓+名两三个字。
2. **禁止表明 {{user}} 的性别，必须模糊化**：不用性别指代，衣着与身体一律抽象处理，不写兜、袢、胸口、性征等部位，也不用"高挑/纤细"堆叠代替。代指 {{user}} 时直接写 {{user}} 。

## 二、七格剧情骨架（每份大纲的主体）

一份完善的开局必须有下面七格，缺一格就会出现"人物凭空出现、互动没有来由"的问题：

| 格 | 要写什么 |
|---|---|
| **① 时间地点** | 几点、在哪、天气；一两个具体细节（气味、声音、季节） |
| **② {{user}} 身份** | 是谁；**身份不是固定项**，可以是授精师，也可以完全不是 |
| **③ 这个身份代表什么** | **权限 + 限制 + 别人凭什么找 {{user}}**。这是整条线的发动机：有权限别人才来求，有限制 {{user}} 才不能随便答应，两样都要写 |
| **④ {{user}} 处在什么地方** | 场所，以及 {{user}} 为什么恰好在这儿 |
| **⑤ 这里有什么人** | 在场人物：每个给「名字 + 年龄 + 职务或身份 + 核心诉求」。诉求必须互不相同，否则会变成几个人重复说同一句恭维 |
| **⑥ 会产生什么互动** | 每个人的诉求怎么落到 {{user}} 身上；**{{user}} 的真实选择点**（必须是两难，不能是"答应就好"） |
| **⑦ 结尾** | **把权限交给玩家**：停在对方把话挑明、**{{user}} 还没做出选择**的那一刻，不写 {{user}} 的答复 |


## 三、自检表（一批大纲写完贴一张）

至少三列：**# ｜ 地点 ｜ ③ 权限 / 限制 ｜ ⑥ {{user}} 的真实选择点**。

## 五、成批出大纲的规矩

- 一批 6~8 份，**地点类型两两不重、③ 的权限与限制两两不重**。
- 身份要铺开：授精师只占一部分，其余可以是普通公民、学生、家属、办事员、外部人员等。
- 骨架共用，**每份只变三样**：谁在接 {{user}}、本地眼下出了什么事、挑明的那句话是什么。
- 已经用过的场景不要再写（老卡占了机场接机、授精部大厅、缺人手、学校排班、母亲替孩子求、街坊母亲开口等）。

# 开局大纲的格式（2026-10-08 改版 · 现行）

一份大纲写四段：**限制 → 剧情 → 人物 → 钩子**。

```
限制：指代 {{user}} 时只能使用 {{user}}，不表明 {{user}} 性别
剧情：{本次开场白的完整剧情，分三段写}
  开头：时间地点、天气、气味或声音等一两个具体细节；{{user}} 此刻正在做什么
  过程：谁先开口、说了什么、做了什么；{{user}} 的身份与处境在这里被牵出来
  结尾：停在**对方把话挑明、{{user}} 还没做出选择**的那一刻，不写 {{user}} 的答复
人物：{每个在场人物一小段：名字、年龄、身份 ＋ 此刻的心理（想要什么／怕什么／怎么看 {{user}}）}
钩子：{2~4 条"之后可以去做、可以发生"的事或场景，供玩家自行展开}
```

几条约定：

- **限制**那一行默认照抄（只用 `{{user}}`、不表明性别）。**若这张卡就是要限定性别**（例如精液当货币世界的「哥哥」「父亲」卡），把这一行改成对应写法：
  `限制：{{user}} 为男性，正文可用哥哥／父亲／爸爸等指代`。
- **剧情**要写"完整剧情"，不是要点罗列 —— 它是给 AI 落正文用的骨架，写清因果与台词，正文才有东西可写。
- **人物**里除了身份，**必须写心理**（想要什么、怕什么、对 `{{user}}` 是什么态度），否则正文里几个人会变成同一张嘴。
- **钩子**不是必发生的事，而是留给玩家的岔路：之后可以去做、可以被触发的场景。2~4 条即可，别写成任务清单。

## 实例（精液当货币的世界 · 收租日那类场景）

```
限制：指代 {{user}} 时只能使用 {{user}}，不表明 {{user}} 性别
剧情：
  开头：夏夜 19:20，老旧公寓四楼走廊，闷热无风，头顶声控灯有一盏在短路闪。{{user}} 拎着两袋菜爬上楼，钥匙刚套进指缝。
  过程：门从里面被拉开 —— 房东金悦倚在门框上，只有一件洗得发白的吊带衫，没穿文胸；玄关里她表妹金小琴拿旧杂志扇风、催她快点。{{user}} 递上准备好的精液券顶房租，金悦弹了一下纸页、把它按回去：「我不收这玩意儿，还得大热天跑银行排队。」她半步跨进走廊，隔着裤子按上 {{user}} 的大腿根部，开出条件：现在就在这儿付进她身上，这个月房租打九折。
  结尾：金悦的手没有拿开，小琴在门口探头看热闹 —— 停在 {{user}} 决定"付还是不付、怎么付"之前，不写答复。
人物：
  · 金悦（26 岁，房东）：下午就开始馋这口，图的是实在的肉体满足；嫌精液券"轻飘飘"，要当场收进身体里。把 {{user}} 当熟客，理直气壮里带点调笑。
  · 金小琴（22 岁，金悦的表妹，来收上季欠的水电）：只想快点收完回去冲澡；对这场面无感、没耐心，说话毫无遮拦。
钩子：
  · 水电那笔要不要一起付、怎么付
  · 门口／玄关／进屋三种地点的差别（楼道里随时可能有人经过）
  · 说好的"打九折"，下个月房租可以拿这件事来讲价
  · 金小琴还在场 —— 她会不会被卷进来，或者替表姐记账
```
