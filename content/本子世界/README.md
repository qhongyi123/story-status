# 本子世界（hentai）状态栏写入内容

本目录集中存放「要写入世界书条目」的文本，供状态栏的三个页面加载后写入对应 uid，不硬编码进 `status.js`。

## 目录结构

- `世界观/`   —— 状态栏「世界观」页面（先做），写入本子世界 uid 54（世界观设定）
- `特殊能力/` —— 状态栏「特殊能力」页面（后做），写入目标条目待定
- `角色状态/` —— 状态栏「角色状态」页面（暂缓）

### 世界观 目录内的分层（uid 54 专用）

```
世界观/
  ├─ 世界风格/{组件名称}.txt           ← 世界规则类组件，文件名直接是组件名
  ├─ 民俗风情/{组件名称}.txt           ← 民俗风情类组件，同上
  └─ 背景设定/{组件名称}-{子组件名称}.txt  ← 子组件，加组件名前缀；不分子目录
```

- 组件文件：文件名直接是组件名称（不加“组件-”前缀）。
- 子组件文件：`{组件名称}-{子组件名称}.txt`（加组件前缀）。

## uid 54 内容格式

```
<本子>
# 世界观与基调设定
## 时代锚点
（现代都市……）
## 世界风格
（世界规则类正文，自然分段）
## 民俗风情
（民俗风情类正文，自然分段）
</本子>

<背景设定>
（世界风格 + 民俗风情 的子组件细节，自然分段）
</背景设定>
```

- 正文不出现“组件”等元概念、不写小标题/标签；“默认接受”直接融进句子。
- 详见任务指导书 §3.5 / §3.6。
